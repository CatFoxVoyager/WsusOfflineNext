# Medium Language Selection: Linux Bash vs Windows CMD Parity

**Last verified:** 2026-11-27 (Milestone v5.1 — Phases 38, 39, 40; tracking #52 / #51)

This document compares multi-language medium generation and client installation across the Windows pipeline (`src-modern/generator/` + `cmd/DownloadUpdates.cmd`) and the Linux/Bash pipeline (`sh/update-generator.bash` + `sh/download-updates.bash`), both feeding the shared client installer (`client/cmd/DoUpdate.cmd`).

## 2. Documented Deliberate Divergences

1. **Default selection on first run:**
   - **Windows modern GUI:** Defaults to `glb` only (0 additional languages checked) so existing users see zero extra downloads (SC4).
   - **Linux `sh/update-generator.bash`:** Keeps the incumbent `deu` + `enu` pre-checked defaults (`10-show-selection-dialogs-with-dialog.bash:169-170`) and requires at least one language token because `sh/download-updates.bash` takes comma-separated `LANGUAGE[,LANGUAGE...]` as `$2` and maps Windows main updates to `glb` internally.
2. **Server 2012 (`w62-x64`) IE11 language-pack landing directory:**
   - **Windows CMD (`cmd/DownloadUpdates.cmd`):** Per-language passes target `client/w62-x64/<lang>/`.
   - **Linux Bash (`sh/download-updates-tasks/60-main-updates.bash:617-624`):** Merges `StaticDownloadLinks-ie11-w62-x64-<lang>.txt` into the `w62-x64-glb` static list, landing in `client/w62-x64/glb/`.
   - **Resolution:** `client/cmd/DoUpdate.cmd` (`:ResolveIEw62LangPack`) checks `..\w62-x64\<OS_LANG>\` first and falls back to `..\w62-x64\glb\`, so media generated by either pipeline install IE11 language packs cleanly without warnings.
3. **Catalog derivation (23 vs 24 entries):**
   - **Windows modern GUI:** Mechanically derives the 23 non-`glb` tokens that have files in `static/StaticDownloadLinks-*.txt` (`enu` has no separate static language list because `glb` already carries English) and pins `English (global) [glb]` as a locked-active first row.
   - **Linux `sh/update-generator.bash`:** Displays all 24 non-`glb` tokens including `enu` (required for the single-command CLI grammar `./download-updates.bash w100-x64 enu`).
